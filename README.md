# Нейроигры для собак

Бесплатное веб-приложение (PWA) для владельцев собак: каталог игр для умственного
развития собаки с пошаговой инструкцией и демонстрацией. Игры проходят офлайн —
приложение даёт инструкцию, владелец играет с собакой.

Типы игр: нюх и поиск, память, мышление, самоконтроль.

Спецификация: [docs/superpowers/specs/2026-10-02-neurogames-design.md](docs/superpowers/specs/2026-10-02-neurogames-design.md)

## Профиль и когнитивный тест

В разделе «Профиль» можно завести собак и пройти с каждой тест из восьми заданий:
нюх, память, мышление, самоконтроль. Результаты показывают, как собака справляется
сейчас, и сравниваются только с её прошлыми тестами, не с другими собаками.
Тест не является ветеринарной диагностикой.

Данные хранятся только в браузере на этом устройстве (`localStorage`), на сервер
ничего не отправляется. Чтобы сделать резервную копию или перенести данные на другое
устройство, нажмите «Сохранить копию» на странице профиля: скачается файл JSON.
«Загрузить копию» заменяет текущие данные данными из такого файла.

Описание: [docs/superpowers/specs/2026-10-03-cognitive-test-design.md](docs/superpowers/specs/2026-10-03-cognitive-test-design.md)

## Запуск

Нужен Node.js 24 или новее.

```sh
npm install
npm run dev      # локальный сервер разработки
npm test         # тесты, включая проверку файлов игр по схеме
npm run build    # проверка типов и сборка в dist/
npm run preview  # просмотр собранной версии
```

## Структура

```
src/
  content/
    games/        по одному JSON-файлу на игру
    schema.ts     схема карточки игры и названия типов
    games.ts      загрузка и проверка всех игр
    youtube.ts    разбор ссылок YouTube для встраивания
  catalog/        фильтрация каталога
  components/     общие элементы интерфейса
  pages/          экраны: каталог и карточка игры
docs/             спецификация
```

## Как добавить игру

1. Создайте файл `src/content/games/<id>.json`; `id` внутри файла должен совпадать
   с именем файла (латиница, цифры, дефисы).
2. Заполните поля по образцу `snuffle-mat.json`. Полный список полей — в спецификации
   и в `src/content/schema.ts`.
3. Видео добавляйте только ссылкой на YouTube, фото — только со свободной лицензией
   и с указанием автора.
4. Запустите `npm test` — тест проверит файл по схеме.

## Публикация

Сайт размещён на Netlify: https://neurodog.netlify.app. При пуше в ветку `main` Netlify сам
собирает проект из репозитория: сначала запускает тесты, и если они упали, сайт не
обновляется. Настройки сборки лежат в `netlify.toml`.

`npm run build:single` собирает весь сайт в один файл `dist-single/index.html`, который
открывается с диска без сервера. В таком режиме видео открываются ссылкой на YouTube:
встроенный плеер с диска не работает.
