# Когнитивный тест для собак — спецификация

Дата: 2026-10-03

## Цель

Владелец проходит с собакой короткий тест из восьми заданий и получает профиль по четырём
навыкам каталога: нюх, память, мышление, самоконтроль. Результаты сохраняются. При
повторном прохождении видно, как изменился каждый навык.

Успех: владелец без посторонней помощи проходит тест по подсказкам приложения за 20–30
минут, видит сильную и слабую стороны собаки, получает игры для слабой стороны, а через
месяц при повторе видит изменения.

## Ограничения и принципы

- Бесплатно, без сервера и регистрации. Данные хранятся в браузере на устройстве
  (localStorage), есть экспорт и импорт файла.
- Собаку сравниваем только с ней же самой. Никаких процентилей и «IQ»: базы норм у нас нет.
- Это не ветеринарная диагностика. Оговорка показывается перед тестом и на экране
  результата.
- При повторе результат может вырасти просто потому, что собака знакома с заданиями. Это
  сказано на экране динамики.

## Профили собак

- При первом входе в раздел «Тест» приложение спрашивает, сколько у владельца собак
  (1–10), и показывает столько форм.
- Поля профиля: имя (обязательно), порода (необязательно), месяц и год рождения
  (необязательно).
- Позже можно добавить собаку, переименовать её или удалить. Удаление спрашивает
  подтверждение и удаляет всю историю тестов этой собаки.

## Задания

Восемь заданий, по два на навык. Каждое оценивается от 0 до 3 баллов. Время в секундах
  округляется вниз до целого.

| № | id | Навык | Задание | Запись | Баллы |
|---|---|---|---|---|---|
| 1 | `towel-find` | Нюх | Лакомство под полотенцем | секундомер | ≤15 с — 3; 16–60 с — 2; >60 с, но нашла — 1; не нашла за 2 мин — 0 |
| 2 | `which-hand` | Нюх | В какой руке? | 3 попытки: верно / неверно | число верных |
| 3 | `delayed-search` | Память | Поиск с задержкой: 2 стаканчика, пауза 30 с | 3 попытки | число верных |
| 4 | `distraction-search` | Память | Поиск после отвлечения: 3 стаканчика, отвлечение 10 с | 3 попытки | число верных |
| 5 | `detour` | Мышление | Обход преграды | выбор исхода | обошла за ≤30 с — 3; обошла дольше — 2; лезет напролом или через верх — 1; бросила — 0 |
| 6 | `empty-cup` | Мышление | Пустой стаканчик | 3 попытки | число верных |
| 7 | `leave-it` | Самоконтроль | Не трогай: лакомство на полу, «нельзя», ожидание до 60 с | секундомер | 60 с — 3; 15–59 с — 2; 3–14 с — 1; <3 с — 0 |
| 8 | `bowl-wait` | Самоконтроль | Ожидание у миски до разрешения | секундомер | ≥15 с — 3; 5–14 с — 2; 1–4 с — 1; не ждёт — 0 |

Для каждого задания в приложении хранятся: название, навык, инвентарь, пошаговая
инструкция, правила оценки, ссылка на похожую игру каталога и источник.
Источники: тест Стэнли Корена (задания 1, 4, 5), Dognition (3, 6, 7), Dog Aging Project (3).

Задание можно **пропустить** с причиной: «собака отказалась», «нет возможности»,
«собака нервничает».

## Подсчёт

- Навык: сумма баллов двух заданий, 0–6. Если одно из заданий пропущено, навык помечается
  «неполный» и показывается балл только за выполненное задание (0–3).
- Общий балл: 0–24, только если выполнены все восемь заданий.
- Сильная сторона — навык с наибольшим баллом, слабая — с наименьшим (среди полных навыков).
  При равенстве показываются все равные. Если полных навыков меньше двух, сильная и слабая
  стороны не определяются.
- Игры для слабой стороны: три игры каталога, у которых этот навык основной, по возрастанию
  сложности. Если слабых навыков несколько, берётся первый в порядке нюх → память → мышление →
  самоконтроль.

## Прохождение

1. **Выбор собаки.**
2. **Подготовка.** Чек-лист: стаканчики, полотенце, лакомства, преграда, миска, тихая
   комната, собака слегка голодна, по возможности помощник. Оговорка «не диагноз».
3. **Задания по одному** в фиксированном порядке 1–8. На экране: что подготовить, шаги,
   секундомер или кнопки попыток, кнопки «Дальше» и «Пропустить». Перед заданием —
   напоминание о стоп-сигналах: если собака нервничает, задание пропускается.
4. **Сохранение после каждого задания.** Незаконченный тест можно продолжить позже. У
   собаки может быть только один незаконченный тест.
5. **Результат.** Баллы по навыкам, сильная и слабая стороны, три игры каталога для слабой
   стороны (того же типа, сначала самые лёгкие), поле для заметки владельца.

Если с прошлого теста этой собаки прошло меньше 30 дней, приложение предупреждает, что
результаты будут менее надёжными, но не запрещает прохождение.

## Динамика

- **История** собаки: список тестов с датой, общим баллом или пометкой «неполный».
  Незаконченный тест показывается сверху с кнопкой «Продолжить» и в графики не входит.
- **Сравнение с прошлым тестом** на экране результата. Прошлый тест — последний завершённый
  тест этой же собаки с той же `protocolVersion`, начатый раньше текущего. Если такого нет,
  блок сравнения не показывается. для каждого навыка и задания —
  прошлый балл и стрелка ↑, ↓ или =. Сравниваются только задания, выполненные в обоих тестах.
- **График** общего балла по датам для полных тестов (SVG без сторонних библиотек), плюс
  мини-график по каждому навыку.
- Текст-подсказка: проводите тест в одинаковых условиях, не чаще раза в месяц; рост на
  втором прохождении частично объясняется знакомством с заданиями.

## Данные

Хранятся в localStorage под ключом `neurogames:v1` одним JSON-объектом, который при
загрузке проверяется схемой (zod).

```
{
  version: 1,
  dogs: [{ id, name, breed?, birthMonth?: "YYYY-MM", createdAt }],
  tests: [{
    id, dogId, protocolVersion: 1, startedAt, finishedAt?,
    tasks: { [taskId]: { status: "done", trials?: boolean[], seconds?: number,
                         outcome?: string, score: 0..3 }
                     | { status: "skipped", reason } },
    note?
  }]
}
```

- Баллы считаются из сырых данных (попытки, секунды, исход) функцией подсчёта и сохраняются
  вместе с ними. Сырые данные хранятся, чтобы при изменении правил можно было пересчитать.
- `protocolVersion` фиксирует версию набора заданий; сравниваются только тесты одной версии.
- Если сохранённые данные не проходят проверку схемой, приложение не падает: показывает
  сообщение и предлагает скачать повреждённые данные файлом и начать заново.

**Экспорт и импорт.** Кнопка «Сохранить копию» скачивает JSON-файл со всеми собаками и
тестами. «Загрузить копию» читает такой файл, проверяет схемой и после подтверждения
заменяет текущие данные.

## Экраны и маршруты

| Маршрут | Экран |
|---|---|
| `#/test` | Собаки: список профилей, кнопка «Пройти тест», история; при первом входе — вопрос о количестве собак |
| `#/test/run/<testId>` | Прохождение: подготовка и задания |
| `#/test/result/<testId>` | Результат и сравнение с прошлым тестом |
| `#/test/dog/<dogId>` | История собаки и графики |

В шапке сайта — переключатель «Игры / Тест». Оформление в текущем мультяшном стиле.

## Тесты

- Модульные: правила подсчёта для каждого задания (граничные значения секунд, число
  попыток), подсчёт навыков и общего балла, неполные навыки, сильная и слабая стороны,
  сравнение двух тестов, проверка и загрузка хранилища, импорт некорректного файла.
- Проверка в браузере (сценарий DevTools, ширина телефона): создание профилей, прохождение
  теста с пропуском, продолжение после перезагрузки, результат, второй тест и стрелки
  динамики, экспорт и импорт.

## Не входит

- Анкета CCDR для пожилых собак — отдельный модуль позже.
- Синхронизация между устройствами и аккаунты.
- Сравнение с другими собаками, процентили, «типы личности».
- Задание «полотенце на голове» — сознательно исключено: может пугать собаку.
