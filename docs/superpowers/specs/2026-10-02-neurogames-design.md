# NeuroGames for Dogs — спецификация MVP

Дата: 2026-10-02

## Цель

Бесплатное веб-приложение для обычных владельцев собак: каталог нейроигр
(игр для умственного развития собаки) с понятной инструкцией и демонстрацией.
Игры проходят офлайн — приложение даёт инструкцию, владелец играет с собакой.

Успех MVP: владелец открывает ссылку на телефоне, за минуту находит подходящую
игру по типу и сложности и может провести её по инструкции без других источников.

## Ограничения

- Решение полностью бесплатное: статический сайт (PWA) на бесплатном тарифе Netlify (https://neurodog.netlify.app),
  без сервера, базы данных и магазинов приложений.
- Аудитория — обычные владельцы, не кинологи. Язык интерфейса — русский.
- Видео не храним: в карточке только ссылка на YouTube, плеер встраивается.
  Фото — только со свободной лицензией или собственные, с указанием автора.
- Данные пользователя не собираются и не хранятся (прогресс не отслеживается).

## Типы игр

| Тип (`type`) | Название | Что развивает |
|---|---|---|
| `scent` | Нюх и поиск | обоняние, концентрация, успокоение |
| `memory` | Память | рабочая и долговременная память |
| `thinking` | Мышление | решение задач, настойчивость |
| `self-control` | Самоконтроль | выдержка, переключение |

Игра может относиться к нескольким типам (например, «напёрстки» — память и нюх).
Коммуникация и трюки в приложение не входят.

## Экраны

1. **Каталог** — список карточек игр: название, типы, сложность (звёзды), время.
   Фильтры: тип (можно выбрать несколько) и сложность (1–5: очень легко, легко, средне, сложно, очень сложно).
2. **Карточка игры** — все поля из раздела «Модель данных»: цель, инвентарь,
   демонстрация (видео/фото), шаги, уровни усложнения, длительность,
   стоп-сигналы, безопасность, адаптации, источники.

На каждой карточке — оговорка: «Это не ветеринарная рекомендация. При проблемах
со здоровьем собаки посоветуйтесь с ветеринаром».

## Модель данных игры

Каждая игра — отдельный JSON-файл в `src/content/games/<id>.json`.
Схема описана в `src/content/schema.ts` и проверяется автоматическим тестом.

| Поле | Тип | Обяз. | Описание |
|---|---|---|---|
| `id` | строка (kebab-case) | да | совпадает с именем файла |
| `title` | строка | да | название игры |
| `types` | массив типов, ≥1 | да | см. «Типы игр» |
| `goal` | строка | да | зачем это собаке, одна фраза |
| `difficulty` | 1–5 | да | сложность игры; показывается шкалой из пяти звёзд |
| `equipment` | массив строк | да | пустой массив — инвентарь не нужен |
| `prepMinutes` | число | да | время подготовки |
| `sessionMinutes` | `{ min, max }` | да | рекомендуемая длительность для взрослой собаки |
| `media` | массив | нет | `{ kind: "youtube", url, title }` или `{ kind: "photo", url, author, license }` |
| `steps` | массив строк, ≥1 | да | пошаговая инструкция |
| `levels` | массив из 3 элементов | да | `{ level, description }` — как усложнять |
| `stopSignals` | массив строк | да | когда прекратить и упростить |
| `safety` | массив строк | да | риски и меры безопасности |
| `adaptations` | объект | нет | `puppy`, `senior`, `small`, `large` — текстовые советы |
| `sources` | массив `{ title, url }`, ≥1 | да | откуда взято описание |

Общие нормы (показываются на карточке): 5–15 минут для взрослой собаки,
2–5 минут для щенка, лучше несколько коротких подходов в день. Признаки
перегрузки: зевание, облизывание, отворачивание, тяжёлое дыхание, потеря интереса.

## Стартовый каталог

51 игра: по 10–14 на тип. Тексты составляются по открытым
источникам (статьи о нейроиграх, исследования когнитивных способностей собак),
видео подбирается поиском на YouTube. Игра без подходящего видео публикуется
без медиа.

## Техника

- React + TypeScript + Vite, `vite-plugin-pwa` (установка на экран, кэш для офлайна).
- Маршрутизация через `HashRouter` (`#/`, `#/games/<id>`) — работает на любом статическом хостинге
  без настройки сервера.
- Контент собирается при сборке через `import.meta.glob`.
- Без интернета работают каталог и тексты; видео — нет.
- Деплой: Netlify собирает сайт из репозитория при пуше в `main` (`netlify.toml`).

## Тесты

- Все файлы игр проходят схему; `id` совпадает с именем файла и уникален.
- Логика фильтрации каталога покрыта модульными тестами.
